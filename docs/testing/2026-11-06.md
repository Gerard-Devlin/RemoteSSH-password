## 0.1.6 — Marketplace icon limit

The first 0.1.5 Marketplace upload was rejected because the 1254 × 1254 source icon exceeded the service's 1024 × 1024 limit. The supplied artwork is scaled to a transparent 512 × 512 PNG. Both documentation checks and the final VSIX verifier now require a square PNG between 128 and 1024 pixels. Authentication and credential storage code are unchanged.

Local formatting/compile, 27 TypeScript unit cases, 14 Go unit cases, 7 localization checks, 6 documentation checks, PowerShell parsing, and the exact 32-entry VSIX verification passed with the corrected 512 × 512 icon. Authentication integration was not repeated locally for this asset-only patch; the preceding results remain in the 0.1.5 section. Hosted CI and the first successful Marketplace publication are checked separately. The existing v0.1.5 GitHub Release is retained without replacing its assets.

## 0.1.2 — Authentication input

Version 0.1.2 addresses the cluttered manual-authentication description. The original server challenge is kept verbatim after a localized label in the masked input's placeholder; the help line is a short localized explanation that the response is not saved. Fixed-password inputs also have an English/Chinese placeholder.

Password recognition, successful-authentication detection, fingerprint matching, and persistence rules are unchanged. A server can ask for a password through keyboard-interactive authentication. The word “Password” in a challenge does not make that response eligible for this preview's fixed-password memory.
