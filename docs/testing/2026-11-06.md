## 0.1.2 — Authentication input

Version 0.1.2 addresses the cluttered manual-authentication description. The original server challenge is kept verbatim after a localized label in the masked input's placeholder; the help line is a short localized explanation that the response is not saved. Fixed-password inputs also have an English/Chinese placeholder.

Password recognition, successful-authentication detection, fingerprint matching, and persistence rules are unchanged. A server can ask for a password through keyboard-interactive authentication. The word “Password” in a challenge does not make that response eligible for this preview's fixed-password memory.
