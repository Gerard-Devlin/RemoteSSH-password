This is a local preview, not a completed real-server Remote-SSH acceptance release. Loopback tests use real Windows OpenSSH and an isolated Go SSH/SFTP server with in-memory UI/storage adapters. ## Coverage in the baseline

- Save only after confirmed password authentication; no commit for a different authentication method, cancellation, closed sessions, or once-only input.
- Effective host/port/username isolation, fingerprint changes, one saved offer, explicit rejection versus network failure, and delayed-save revocation.
- OTP/passphrase/unrecognized prompts remain manual; concurrent matching input is merged without a persistent native cache.
- Compare-and-restore settings preserves later user changes.
- Real `-V`/`-G` compatibility, stdin and nonzero remote exit status, long/unterminated stderr, adjacent SCP-to-SFTP upload, PTY request, and local forwarding.
- First-trust rejection sends no password; forged pre-auth banners cannot trigger a saved credential.
- Wrong-password replacement, different users/ports, cancel without an empty-password attempt, broker restart and multiple brokers.
- Disconnect/handshake timeout, closing a session during input, broker death, unauthorized pipe clients, and stale window routes.
- Disabled/hash-changed/missing-broker fallback, changed host-key rejection, and new-fingerprint re-entry.
- Synthetic passwords absent from process stdout/stderr and non-binary runtime files. This is not a process-memory audit or a claim about ordinary Remote-SSH fallback internals.

## Blocked real-host validation

Two isolated VS Code host attempts on 2026-11-05 stopped before extension-host assertions. VS Code reported an update in progress, and logs identified the `vscode-updating` mutex remaining held after a 30-second wait.

The updater was not terminated and the lock was not forced open. **The host test did not pass. Actual SecretStorage assertions did not run.** It must be rerun when the installed VS Code update completes; fixture preparation alone is not acceptance.

## Remaining acceptance

The [manual checklist](../testing.md#manual-acceptance) remains open, including actual English/Chinese native UI, early Remote-SSH activation, real SecretStorage across a full restart, complete VS Code Server installation/SCP upload, terminals/forwarding, real multiple windows/reloads/reconnects, password/key changes, and real disable/uninstall recovery.

The GitHub workflow has not been executed on a hosted repository as part of this local report.

## Reproduce

Run `npm run check`, `npm run test:integration`, `npm run test:extension`, `npm run test:race`, `go vet ./...` in native, `npm run package`, and `npm run verify:package`. Inspect ignored result JSON under artifacts. Run `npm run test:host` separately with an explicit Code.exe path if autodetection is unavailable.
