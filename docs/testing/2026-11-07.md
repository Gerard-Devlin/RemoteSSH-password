## Remaining acceptance

CI is configured for Windows x64, Apple Silicon macOS and Intel macOS. Full visual Remote-SSH acceptance and macOS real SecretStorage restart acceptance remain manual. Previous Windows host evidence is in the [2026-11-06 report](2026-11-06.md).

macOS keeps later keyboard-interactive prompts manual after a rejection or partial continuation. Reconnect to remember a replacement password. This avoids trusting server-provided authentication-list diagnostics.

## 0.3.1 reconnect regression

The macOS acceptance run exposed a stale-generation upgrade path: `bridge.json` in a new helper generation could name an older helper generation as `realSSH`. The later connection then created a nested wrapper while ASKPASS was scoped to the outer generation, so fixed-password prompts failed and OpenSSH exited after repeated attempts.

Setup now enumerates every existing `bridge-v2` generation and excludes all managed wrappers from real-OpenSSH recovery candidates. The native `ssh` launcher also follows old generation metadata directly to the real executable without executing nested wrappers, and falls back to ordinary OpenSSH when a chain is invalid or cyclic.

Regression results on macOS arm64 with Apple OpenSSH 10.5p1:

- TypeScript unit suite: 51 passed, including both Windows and macOS path cases for stale `bridge-v2` selection.
- Native unit and race suites passed; `go vet` passed.
- Windows x64 native tests and all four desktop helper executables cross-compiled successfully with CGO disabled. Windows runtime execution still requires a Windows runner.
- Real macOS OpenSSH loopback integration: 28 passed.
- English and Simplified Chinese compiled-extension suites: 19 passed in each locale.

## 0.3.2 Remote-SSH routing regression

Remote-SSH 0.128.0 on VS Code 1.145.2 can start a local-server process whose environment does not contain the extension host's `SSHPM_WINDOW_PIPE`. Version 0.3.1 treated that as an unavailable broker and passed the connection to ordinary OpenSSH, so Remote-SSH displayed its own password input.

The 0.3.2 regression suites remove `SSHPM_WINDOW_PIPE` entirely while retaining only the shared VS Code instance identity. The compiled extension still receives its own masked input, saves only after confirmed authentication, and reuses the saved password on reconnect. Native tests also cover focus selection between multiple windows in the same VS Code process and isolation from another instance.

Real macOS arm64 acceptance used two active Remote-SSH windows without reading or recording any credential value:

- Both windows started a 0.3.2 native broker and reported that the local authentication service was ready.
- A saved password authenticated one host through OpenSSH's `password` method.
- A saved fixed password authenticated the other host through `keyboard-interactive`.
- Neither active connection spawned Remote-SSH's native askpass prompt.
