# Local validation — 2026-11-07

[Testing guide](../testing.md) · [Compatibility](../compatibility.md)

This change adds macOS arm64/x64 and fixes the minimum VS Code version that rejected installation on 1.136.1. No production credentials or user settings were used.

## Environment

- Local macOS arm64 host; Apple system OpenSSH 10.3p1, LibreSSL 3.3.6.
- Go 1.26.1; Node.js 24.22.1; TypeScript compiled against `@types/vscode` 1.85.0.
- Fixture storage, SSH config and known_hosts are isolated under ignored `.test-runtime` directories.

## Results

- Real macOS OpenSSH loopback: 28 cases passed, including password save/reuse, rejected password replacement, SCP/SFTP, PTY, forwarding, host-key changes, forged banners, cancellation, broker failure, multi-window coordination and unauthorized local clients.
- `npm run check` passed: 50 TypeScript tests, 7 localization tests, 6 documentation tests, and the native Go suite. `go vet` and `go test -race` passed on macOS.
- Native macOS transport checks cover kernel executable identity, peer UID/PID, private socket permissions, exclusive listeners, and private FIFO streaming/cleanup.
- English and Chinese extension-entry suites passed all 19 cases each. They exercise the compiled extension and real helpers with a mocked VS Code API; this is distinct from a real editor host.
- All three platform packages built and passed verification against source bytes and PE/Mach-O architecture before delivery; receipts and hashes are under ignored `artifacts`.

## Remaining acceptance

Windows execution and Intel Mac execution require their respective runners; cross-compilation alone does not establish runtime compatibility. CI is configured for Windows x64, Apple Silicon macOS and Intel macOS. Full visual Remote-SSH acceptance and macOS real SecretStorage restart acceptance remain manual. Previous Windows host evidence is in the [2026-11-06 report](2026-11-06.md).

macOS keeps later keyboard-interactive prompts manual after a rejection or partial continuation. Reconnect to remember a replacement password. This avoids trusting server-provided authentication-list diagnostics.
